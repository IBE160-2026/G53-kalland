Direction 06: Client-centric

Every image lives under someone. The sidebar is a client tree (client, then project), the library opens inside a client’s folder, and uploads start from a client so visibility defaults follow. Clients get the same idea turned around: the portal is Fjordkaffe’s own folder, with the agency’s wider catalogue beside it.
