# Pilot image sources

The 20 images for the [pilot](pilot-plan.md) all come from Wikimedia Commons. Each is released as CC0 or marked public domain on its file page (checked through the Commons API on 2026-10-28). Both allow commercial use and changes without attribution; the authors are listed anyway.

The images are kept local and not committed (see `.gitignore`). To rebuild `images/`, download each original from its file page into `images/original/<file>`, then make a copy with the long edge capped at 1568 px in `images/1568/` (`sips -Z 1568`, which keeps EXIF, GPS and IPTC).
