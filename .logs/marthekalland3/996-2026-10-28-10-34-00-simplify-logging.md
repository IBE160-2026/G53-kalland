# Simplify logging

## 2026-10-28 kl. 10:34 — marthekalland3

### Oppgave
Review and simplify the user's own process logging (`/wrap-up`, `/commit-logs`, the hooks), which took too long and used too many tokens. It also had to work with several Claude sessions writing code at the same time. The teacher's `sesjonslogg` skill is left unchanged.

### Plan
- Shorten `/wrap-up`: no draft in the chat, no repeat of what `sesjonslogg` writes, transcript only from the SessionEnd hook, `grep` instead of reading whole files.
- One git worktree per code session; the hooks and `/wrap-up` write all process files to the main folder.
- The prompt hook prints the session ID on `/wrap-up`, so parallel sessions are never mixed up.
- `/wrap-up` commits, pushes and opens the PR after one confirmation, and runs `sesjonslogg`.
- Terminal scripts: `start.sh`, `finish.sh`, `commit-logs.sh` in `.claude/scripts/`.
- Decision: D-016 in `docs/process/decisions.md`.
