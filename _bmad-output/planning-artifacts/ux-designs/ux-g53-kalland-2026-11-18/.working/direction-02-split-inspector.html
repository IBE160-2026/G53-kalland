Direction 02: Split inspector

The grid is a light table and the right-hand inspector is the loupe: pick an image and its access, metadata and actions are always in the same place, so Ida never leaves the grid to edit. The left sidebar holds scope (filters, batch settings) and folds away; the inspector stays. Cyanotype blue for action, sepia only for price.
