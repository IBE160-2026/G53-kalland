### Oppgave
Add a way to write personal reflection notes at the end of each session, tied to that session, to use for the reflection part of the assignment at the end of the project. The notes are to be kept completely separate from prompts, transcripts and session logs.

### Plan
- Checked how `/wrap-up` and the hooks work: the `UserPromptSubmit` hook logs every chat message and the transcript saves the whole conversation, so a reflection typed in the chat would be logged. Decided that the user writes in their own editor instead.
- Claude first suggested a hidden `.reflections/` folder outside the repo's versioned files. The user wanted everything in the repo; it became `docs/reflections/`.
- Discussed pushing the notes. The user chose to keep them local (gitignored) for now.
- The user added the course's reflection report template (Norwegian). Claude translated it and mapped six per-session questions to the template's sections. The user accepted the questions and declined a separate `/reflect` command for mid-session notes.
